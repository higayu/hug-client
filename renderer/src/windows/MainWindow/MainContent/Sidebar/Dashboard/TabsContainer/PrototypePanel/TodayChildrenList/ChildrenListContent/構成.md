| 種別           | 通常時          | hover時              | 選択時           | 選択時ボーダー           |
| ------------ | ------------ | ------------------- | ------------- | ----------------- |
| 通常（全タブ共通） | `bg-gray-50` | `hover:bg-gray-200` | `bg-cyan-200` | `border-cyan-700` |
| 退室済み       | `bg-yellow-50` | `hover:bg-yellow-200` | `bg-yellow-200` | `border-yellow-600` |
| 欠席         | 上記に `grayscale opacity-30` を付与（色は変更しない） | | | |

判定:

- **欠席**: `column5` が「欠席」で始まる
- **退室済み**: `column5` と `column6` がともに `HH:MM` 形式（`AttendanceActionSection` の専門的支援ボタン表示条件と同じ）
