デスクトップアプリで「マイクの使用が許可されていません。」と表示される原因

■ 症状
音声認識機能を使用すると、
「マイクの使用が許可されていません。」
というエラーメッセージが表示される。

■ 原因
音声認識では以下の処理でマイクへのアクセスを要求している。

navigator.mediaDevices.getUserMedia({ audio: true })

この処理が失敗し、例外名が「NotAllowedError」の場合に

setError("マイクの使用が許可されていません。");

を実行してエラーメッセージを表示している。

■ Electron側の設定
Electron側ではマイク権限の設定は実装済み。

・main/permissions.js
  media
  microphone
  を true に設定

・main.js
  Permission Handler を初期化済み

そのため、Electron側の実装が原因である可能性は低い。

■ 主な原因

① Windowsのマイク権限が無効

最も多い原因。

Windowsの

設定
→ プライバシーとセキュリティ
→ マイク

から以下が有効になっていることを確認する。

・マイクへのアクセス
・アプリにマイクへのアクセスを許可
・デスクトップアプリにマイクへのアクセスを許可

② 他アプリがマイクを使用中

以下のようなアプリがマイクを占有している場合、取得できないことがある。

・Zoom
・Teams
・Discord
・録音ソフト
・Webブラウザ

不要なアプリを終了して再度確認する。

③ ブラウザで実行している

Electronではなく

http://localhost:5173

などをブラウザで開いている場合は、ブラウザ側でマイク権限が拒否されている可能性がある。

ブラウザのサイト設定からマイクの許可状態を確認する。

④ 別Session・WebViewで実行している

BrowserWindowやWebViewなど別Session上で実行している場合は、Permission Handlerが適用されていない可能性がある。

■ 調査方法

DevToolsで例外内容を確認する。

console.error(e);

特に以下を確認すると原因の切り分けがしやすい。

e.name
e.message

例

NotAllowedError
Permission denied

■ 今回の原因

Windowsのマイク設定で「デスクトップアプリにマイクへのアクセスを許可」が無効になっていたことが原因だった。

この設定を有効にすることで、Electronデスクトップアプリから正常にマイクへアクセスできるようになり、音声認識が動作するようになった。
