# 入退室ボタン未検出バグ修正（2026-10-07）

## 原因
入退室対象一覧は最新HTMLを fetch() して取得している一方、
操作用の `hug-automation-webview` は同じURLを開いている場合に再読み込みを省略していました。

そのため、一覧データ上では `#leave{r_id}` / `#enter{r_id}` が存在していても、
操作用WebViewのDOMが一つ前の状態のままで、断続的に
「入室/退室ボタンが見つかりません」が発生する可能性がありました。

## 修正
`attendance/_shared/webview.js` を変更しました。

- 同じ出席詳細URLでも入退室実行前に必ず `webview.reload()` する
- ナビゲーション開始前に `did-finish-load` の監視を開始する
- 読込後に対象日 `input[name=date]` と出席表テーブルの生成完了を確認する
- 読込失敗・タイムアウトを明示的なエラーにする

DB定義の変更は不要です。
