# OpenProfessionalSupport
ProfessionalSupport ディレクトリを既存の同名ディレクトリへ上書きしてください。旧ファイルは互換性のため残しています。

管理パネルの専門的支援ボタン → 一時メモ2取得 → 新規HUGタブ → 初期設定 → Rendererモーダル。
入力欄に反映は未保存。反映して下書き保存は HUG 標準ボタンを一度クリックします。直接POSTは行いません。
施設IDのDOM確認ができない場合は自動クリックを無効にします。HUG画面で対象を確認して手動保存してください。
保存成功は未検証のため、専門＋の自動登録は停止しています。HUGで保存結果を確認し、管理パネルで専門＋登録・状態確認を実行してください。
通常保存・既存記録検索は未実装です。新規作成専用なので既存記録の有無を確認してから使用してください。
Flow 25 や他のFlow、個人記録は変更していません。

検証: ログイン済みのテスト施設で児童・職員・日付・時刻・施設、改行、タブ切替、閉じる、保存結果を確認してください。実環境未検証です。
